zmk-config for charybdis (4x6)

## RGBと省電力

左右ともnice!nano v2のnRF52840 VBUS検出でUSB給電を判定します。

- USB給電中：無操作でもRGBを点灯し続け、深いスリープに入りません。
- バッテリー中：約30秒無操作でRGBを消灯し、操作で復帰します。約15分無操作で深いスリープに入ります。
- USBを抜いた時点ですでに無操作状態なら、最大約1秒で消灯します。無操作中のUSB給電復帰も最大約1秒で再点灯します。
- 手動のRGB OFFは優先します。RGB ON/OFF・色・効果の保存は維持し、自動消灯や給電の変化では保存領域を書き換えません。

無操作の判定範囲は従来のZMKと同じです。右側（central）は左右のキー入力とトラックボール入力、左側（peripheral）は左側のキー入力を検出します。バッテリー中の左右の無操作状態を同期する機能はありません。

PCのシャットダウン後もUSBポートが給電し続ける場合はRGBも点灯し続けます。シャットダウンで消灯させるにはPC側でUSB給電が止まる必要があります。

## 実装・ビルド

`zephyr/module.yml`により、このリポジトリをローカルZephyrモジュールとして読み込みます。`CONFIG_CHARYBDIS_VBUS_POWER=y`のときだけ、ZMK v0.3の`activity.c`と`rgb_underglow.c`のコピーに`module/patches/zmk-v0.3-vbus.patch`を適用し、そのコピーをコンパイルします。westで取得するZMK本体やキャッシュは変更しません。

RGB制御と深いスリープは、左右とも`module/include/charybdis/vbus_power.h`の同じ読み取り専用検出を使います。USBやPOWER/CLOCKの割り込み設定には介入しません。設定リセット用ファームウェアではこの処理を有効にしません。

GitHub Actionsで状態遷移テストと左右のビルドを実行します。ローカルでの状態遷移テストは、ZMK v0.3のチェックアウトを指定します。

```sh
python3 tests/test_vbus_policy.py --zmk-source /path/to/zmk/app/src
```

ZMKを更新するときはパッチの互換性を確認してください。パッチが適用できない場合はビルドを失敗させ、元の処理へ黙って戻らないようにしています。

書き込みは左右両方必要です。`settings_reset`は通常の書き込みには使いません。実機では、USB給電中に15分以上放置しても点灯が続くこと、バッテリー中の消灯とキー操作での復帰、給電の抜き差し、手動OFFが維持されることを確認します。
